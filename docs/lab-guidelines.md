# 实验编写规范

- 先画清楚架构，再编写代码。
- 每个实验保持自包含，禁止实验之间共享运行时状态。
- 优先使用 Terraform 定义基础设施。
- 优先使用 LocalStack 或其他本地模拟器。
- 正向路径必须是真实的服务调用，而不是只返回固定 JSON 的假接口。
- 自动化验证必须包含正向路径和负向 / 故障场景。
- 文档要记录实际观察到的证据、版本和模拟器差异。
- 不把令牌、密码或真实个人信息写入代码、状态样例或文档。

如果实验声称存在 `EventBridge → Step Functions → Lambda`，实际执行必须真的穿过这些服务；如果实验声称存在 `Cognito → API Gateway → Lambda → MCP`，实际执行也必须穿过这条链路。单元测试不能替代端到端证据。

每个实验都应当能够在已经运行的本地 LocalStack 上独立执行。脚本不应默认创建或管理 LocalStack 容器。
